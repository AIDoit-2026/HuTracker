# 需求澄清结果

当前暂无未决问题。以下内容是基于 `Requirement.md` 和后续确认形成的实现依据。

## 已确认决策

- 首版支持 2~4 人。
- 玩家按输入顺序分配东、南、西、北座位。
- 2 人和 3 人局按实际参与玩家轮庄。
- 圈按东、南、西、北循环。
- 圈庄固定推进：每记一笔推进一次庄家，庄家回到第一位玩家后推进一圈。
- 4 人局是 16 笔完成东南西北一轮；2 人或 3 人局是 `playerCount * 4` 笔完成一轮。
- 不处理连庄、流局、庄家胡牌等真实麻将推进变体。
- 等额记分模式默认开启。
- 等额模式下只记录胡牌人的正分，不记录逐笔负分。
- 等额模式的最终结算按各玩家得分合计计算差额，分少的给分多的。
- 非等额模式允许正分、负分和 0，但一笔记录内所有玩家分数总和必须为 0。
- 非等额模式下所有正分都计为胡牌，不需要额外指定胡牌人。
- 胡牌次数按正分记录统计。
- 记录在结算前允许修改，结算后锁定为只读。
- 首版提供历史牌局列表，可继续最近牌局，可删除牌局。
- 数据导入导出使用 JSON 完整数据格式。
- 结算页额外支持 CSV 分享当前牌局明细。
- Android 技术基线为 Kotlin + Jetpack Compose + Room。
- 最低 Android 版本为 Android 8.0。

## 后续变更需要重新确认的点

- 是否要支持超过 4 人。
- 是否要严格保留 16 笔一轮，即使是 2 人或 3 人局。
- 是否要支持连庄、流局、补记圈庄或手动调整圈庄。
- 是否需要结算后撤销锁定并继续修改记录。
- 是否需要导出单个牌局之外的更多分享格式。
