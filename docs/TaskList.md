# 任务清单

## 阶段 0：需求确认

- [x] 确认首版支持人数范围：2~4 人。
- [x] 确认等额模式输入分数的含义：只记录正分，结算时再算差额。
- [x] 确认圈庄是否固定推进，是否处理连庄和流局：固定推进，不处理连庄和流局。
- [x] 确认 2 人、3 人牌局的庄家显示方式：按实际参与玩家轮庄。
- [x] 确认导入导出的格式和范围：JSON 导入导出完整数据，CSV 分享当前牌局明细。
- [x] 确认最低 Android 版本和是否采用 Jetpack Compose：最低 Android 8.0，Kotlin + Jetpack Compose + Room。
- [x] 确认记录修改规则：结算前允许修改，结算后锁定。
