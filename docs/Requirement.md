# 胡牌追踪器-一款麻将自动算番记分工具

## 目标
一个麻将胡牌记分的小工具 安卓版

## 特点
单机，原生安卓开发，数据可以导出和导入

## 客户端功能描述
- 牌局开始前设置
  是否等额记分（胡牌后其余每人扣分相同） 默认是
   - 是 只需要记录得分 
   - 否 需要记录每人的得分和失分


- 开始牌局，输入3~4个人的名字或代号以后就开始新的记分，2人或2人以上都可以开始
- 记一笔： 如果设置了等额，只需点一下得分人然后输入分数。否则每个人都需要输入分数，并且正数=负数之和
- 自动完成记录
  麻将分为东南西北四个方向，起始状态是东风圈东风庄。圈和庄都是东南西北循环，先循环庄家，再循环圈。
  每记录一笔都自动显示当前的圈和庄
  16笔为一个循环
- 结算
  计算出每个人的积分总和，等额模式需要额外计算差额，分少的需要依次给分多的结算差额，统计出每个人的总差额（有正有负）
  计算出各人的胡牌次数（得分次数）
  计算出各人平均每次得分
